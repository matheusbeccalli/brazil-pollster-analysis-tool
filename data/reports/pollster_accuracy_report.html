Relatorio de Precisao dos Institutos de Pesquisa Eleitoral

Resumo Executivo

Analise de 531 pesquisas finais pre-eleitorais de 100 institutos de pesquisa. Este relatorio foca nos 13 institutos que pesquisaram ao menos uma eleicao presidencial e possuem 5+ observacoes totais (incluindo governadoriais) — dados suficientes para uma comparacao significativa. Os 5 mais precisos (por erro absoluto medio):

  1. Futura — EAM 2.24 pp (6 disputas)
  2. MDA — EAM 2.33 pp (6 disputas)
  3. Datafolha — EAM 3.64 pp (49 disputas)
  4. Quaest — EAM 3.87 pp (7 disputas)
  5. IBOPE/Ipec — EAM 3.88 pp (183 disputas)

Dados: Poder360 via Base dos Dados. Resultados oficiais: TSE.

Como Ler as Metricas

Todos os valores de erro sao em pontos percentuais (pp). Por exemplo, se um instituto previu que um candidato obteria 45% e o resultado real foi 48%, o erro e de 3 pp.

ColunaO que significaComo interpretar
NNumero de disputas observadas Mais disputas = ranking mais confiavel. Um instituto com 50 disputas e muito mais confiavel que um com 5.
EAMErro Absoluto Medio sobre os 2 candidatos mais votados A principal metrica de precisao. Menor e melhor. Um EAM de 3 pp significa que as previsoes do instituto erraram em media 3 pontos percentuais por candidato. Abaixo de 5 pp e bom; acima de 10 pp e ruim.
Mediana EAMO valor central de todas as observacoes de EAM Menos sensivel a valores extremos que a media. Se a mediana for muito menor que a media, o instituto teve alguns erros muito grandes, mas geralmente e razoavel.
IC Inf / IC SupIntervalo de confianca bootstrap de 95% para o EAM medio O erro medio verdadeiro provavelmente esta neste intervalo. Intervalos mais largos indicam menos certeza (geralmente porque o instituto tem menos observacoes).
Erro de MargemErro medio na diferenca prevista entre os 2 candidatos mais votados Mede o quao bem o instituto captou a dinamica competitiva da disputa, nao apenas os votos individuais. Um instituto pode ter EAM baixo mas erro de margem alto se os erros em ambos os candidatos forem na mesma direcao.
Vies Esq.Erro medio com sinal para candidatos de esquerda (positivo = superestimou) Valores positivos significam que o instituto sistematicamente superestima candidatos de esquerda. Negativo significa subestimacao. Valores proximos de zero indicam ausencia de vies sistematico.
Vies Dir.Erro medio com sinal para candidatos de direita (positivo = superestimou) Mesma interpretacao do Vies de Esquerda, mas para candidatos de direita. Um instituto que superestima a esquerda tipicamente subestima a direita (e vice-versa).

Metodologia

Fontes de Dados

Os dados de pesquisas vem do banco de dados do Poder360, acessado via Base dos Dados (uma iniciativa brasileira de dados abertos que espelha conjuntos de dados publicos no Google BigQuery). Os resultados oficiais das eleicoes vem do TSE (Tribunal Superior Eleitoral), tambem acessados via Base dos Dados.

Selecao de Pesquisas

Para cada combinacao de instituto x disputa (definida por ano, turno, cargo e estado), selecionamos a ultima pesquisa publicada antes do dia da eleicao — aquela com a data de campo/publicacao mais recente. Se uma pesquisa contiver multiplos cenarios (diferentes composicoes de candidatos), selecionamos o cenario que inclui os dois candidatos mais votados no resultado oficial e que possui o maior numero de candidatos (composicao mais completa).

Rebase para Votos Validos

Os percentuais brutos das pesquisas incluem indecisos, brancos e nulos no denominador. Os resultados oficiais sao reportados como proporcao dos votos validos apenas. Para torna-los comparaveis, rebaseamos os percentuais das pesquisas:

pct_valido = pct_bruto / soma(pcts_brutos_todos_candidatos) x 100

Isso remove indecisos/brancos/nulos da base. Apenas os percentuais rebaseados dos 2 candidatos mais votados sao usados nos calculos de erro.

Metricas de Erro

A metrica principal e o EAM (Erro Absoluto Medio) sobre os 2 candidatos mais votados, tambem conhecido como Medida de Mosteller 3. Para cada pesquisa: EAM = (|erro_candidato_1| + |erro_candidato_2|) / 2. O EAM e entao calculado como media de todas as disputas para cada instituto.

Erro de margem mede o quao bem o instituto previu a diferenca entre os dois candidatos lideres: |margem_prevista - margem_real|.

Vies partidario e calculado como o erro medio com sinal para candidatos classificados como de esquerda ou de direita (baseado na filiacao partidaria). Um vies de esquerda positivo significa que o instituto sistematicamente superestimou candidatos de esquerda.

Intervalos de Confianca

Os intervalos de confianca de 95% sao calculados via reamostragem bootstrap (10.000 iteracoes, reamostrando os valores de EAM por disputa do instituto com reposicao). O intervalo representa a faixa em que o erro medio verdadeiro do instituto provavelmente se encontra.

Identidade dos Institutos

O IBOPE (que encerrou operacoes em janeiro de 2021) e o Ipec (fundado por ex-funcionarios do IBOPE) sao tratados como uma unica entidade ("IBOPE/Ipec") para manter a continuidade entre ciclos eleitorais.

Limiar Minimo de Observacoes

Apenas institutos com 5 ou mais observacoes de disputas sao incluidos neste relatorio. Institutos com menos observacoes sao excluidos porque seus rankings seriam pouco confiaveis — uma unica disputa com sorte ou azar dominaria sua media.

Cobertura

Esta analise abrange eleicoes presidenciais e para governador, ambos os turnos, para os anos cobertos pela janela de analise. A janela padrao e 2014–2022 (tres ciclos eleitorais). Todos os dados a partir de 2000 estao disponiveis para analise estendida.
